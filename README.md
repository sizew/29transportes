# 29 Transportes

Landing page da 29 Transportes, desenvolvida com React, TypeScript, Vite, GSAP e Framer Motion.

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

## Publicação na Vercel

Importe este repositório na Vercel. O projeto usa Vite; as configurações padrão são:

- Comando de build: `npm run build`
- Diretório de saída: `dist`
- Comando de instalação: `npm install`

Os arquivos estáticos da marca e da galeria ficam em `public/`.
